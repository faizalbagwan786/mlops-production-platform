# MLOps Production Platform

A modular, production-grade MLOps platform designed to streamline the lifecycle of machine learning models from development to deployment. This project demonstrates best practices in engineering, automation, and maintainability for real-world ML workflows.

---

## Project Structure

```
mlops-production-platform/
├── app/                        # FastAPI application for model serving
│   ├── main.py
│   ├── model_loader.py
│   ├── schema.py
│   ├── model/                  # Model artifacts
│   │   └── churn_model.pkl
│   └── __pycache__/
├── training/                   # Model training and evaluation scripts
│   ├── train.py
│   ├── evaluate.py
│   └── __pycache__/
├── pipelines/                  # Orchestration and automation pipelines
├── data/                       # Data storage
│   ├── raw/
│   │   └── churn.csv
│   └── processed/
├── monitoring/                 # Monitoring and observability components
├── docker/                     # Containerization assets
├── requirements.txt            # Project dependencies
└── README.md                   # Project documentation
```


---

## Goal

To provide a robust, extensible foundation for managing the end-to-end machine learning workflow, including data processing, model training, evaluation, deployment, and monitoring. The platform is designed for clarity, reproducibility, and ease of integration with modern MLOps tools.

---

## Current Milestone

**Milestone 3: Inference API Complete**

- End-to-end training pipeline with an evaluation gate for controlled model promotion
- FastAPI-based inference service exposing a `/predict` endpoint
- Input validation using Pydantic schemas
- Model artifacts are generated by the pipeline and intentionally not committed to version control

## Getting Started

### 1. Install dependencies
```bash
# 1. Install dependencies
pip install -r requirements.txt
```

### 2. Run the training pipeline
```bash
python training/train.py
```

### 3. Start the inference API
```bash
uvicorn app.main:app --reload
```

---

## Inference API

The project includes a FastAPI-based inference service that serves churn predictions via a REST API.

**Features:**
- Loads the promoted model at application startup
- Validates incoming requests using Pydantic
- Accepts JSON input and returns predictions
- Designed for containerization and deployment in later milestones

**Test the API locally using Swagger UI:**
http://127.0.0.1:8000/docs
