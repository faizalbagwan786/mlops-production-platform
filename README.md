# MLOps Production Platform

A modular, production-grade MLOps platform designed to manage the full lifecycle of machine learning models from training to deployment.  
This project focuses on **engineering best practices, automation, and maintainability** rather than model performance alone.

---

## Project Structure

mlops-production-platform/
├── app/ # FastAPI application for inference
│ ├── main.py
│ ├── model_loader.py
│ ├── schema.py
│ └── model/ # Generated model artifacts (not versioned)

## Goal

Build a **real-world MLOps system** that demonstrates how machine learning models are:

- Trained with reproducibility
- Evaluated before promotion
- Served via a production-ready API
- Containerized for deployment
- Prepared for monitoring, CI/CD, and retraining

## Current Milestone

### Milestone 4: Dockerized Inference Service

Completed features:

- End-to-end training pipeline with evaluation gate
- FastAPI-based inference service (`/predict`)
- Input validation using Pydantic schemas
- Model loading at application startup
- Dockerized API runnable locally or on a server
- CI pipeline using GitHub Actions

Model artifacts are generated by the pipeline and **intentionally not committed** to version control.

## Getting Started

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

```bash
python training/train.py
```

This will generate the trained model artifact in:

```
app/model/churn_model.pkl
```

### 3. Run the API Locally

Start the FastAPI server:

```bash
uvicorn app.main:app --reload
```

Access Swagger UI:

http://127.0.0.1:8000/docs

## API Usage

### Health Check


**GET** `/health`

### Predict Churn

**POST** `/predict`

Request body example:

```json
{
  "age": 30,
  "monthly_charges": 2500,
  "tenure": 12,
  "contract_type": "month-to-month"
}
```

Response example:

```json
{
  "prediction": 1
}
```

## Docker Support

The inference service is fully containerized.

**Build the image:**

```bash
docker build -t churn-api -f docker/Dockerfile .
```

**Run the container:**

```bash
docker run -p 8000:8000 churn-api
```

Swagger UI will be available at:

http://localhost:8000/docs
