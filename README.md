
# MLOps Production Platform

This project is a modular, production-grade MLOps platform that streamlines the lifecycle of machine learning models from development to deployment. It demonstrates best practices in engineering, automation, and maintainability for real-world ML workflows.

---


## Project Structure

```
mlops-production-platform/
├── app/            # FastAPI app for model serving
│   ├── main.py
│   ├── model_loader.py
│   ├── schema.py
│   └── model/      # Model artifacts
├── training/       # Model training and evaluation
│   ├── train.py
│   ├── evaluate.py
├── pipelines/      # Automation pipelines
├── data/           # Data storage
│   ├── raw/
│   │   └── churn.csv
│   └── processed/
├── monitoring/     # Monitoring components
├── docker/         # Docker assets
├── requirements.txt
└── README.md
```


---


## Goal

Provide a robust, extensible foundation for managing the end-to-end machine learning workflow: data processing, model training, evaluation, deployment, and monitoring. The platform is designed for clarity, reproducibility, and easy integration with modern MLOps tools.

## Getting Started

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the model

```bash
python training/train.py
```

### 3. Start the inference API

```bash
uvicorn app.main:app --reload
```

## Inference API

The FastAPI service serves churn predictions via a REST API.

**Features:**
- Loads the trained model at startup
- Validates requests with Pydantic
- Accepts JSON input, returns predictions
- Ready for containerization and deployment

**Test locally:**
Open [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) for Swagger UI.

**Example request:**

```json
POST /predict
{
	"age": 30,
	"monthly_charges": 2500,
	"tenure": 10,
	"contract_type": "month-to-month"
}
```

**Example response:**

```json
{
	"prediction": 1
}
```

## Docker Support

The inference service can be containerized with Docker.

**Build and run locally:**

```bash
docker build -t churn-api -f docker/Dockerfile .
docker run -p 8000:8000 churn-api
```

Once running, the API is available at: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
