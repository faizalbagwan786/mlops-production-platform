
# MLOps Production Platform

A modular MLOps platform focused on managing the lifecycle of machine learning models from training to deployment. This project demonstrates best practices in engineering, automation, and maintainability for real-world ML workflows.

The emphasis is on maintainability, automation, and clear separation of responsibilities rather than model performance.


## Project Structure

```
.
├── app/           # FastAPI application for model serving
│   ├── main.py
│   ├── model_loader.py
│   ├── schema.py
│   └── model/
├── training/      # Model training and evaluation scripts
│   ├── train.py
│   └── evaluate.py
├── pipelines/     # Orchestration and automation pipelines
├── data/          # Data storage
│   ├── raw/
│   │   └── churn.csv
│   └── processed/
├── monitoring/    # Monitoring and observability components
├── docker/        # Containerization assets
├── requirements.txt
└── README.md
```

## Goal

To provide a robust, extensible foundation for managing the end-to-end machine learning workflow, including data processing, model training, evaluation, deployment, and monitoring. The platform is designed for clarity, reproducibility, and ease of integration with modern MLOps tools.

## Current Milestone

**Milestone 1: Training Pipeline Complete**

- Automated training pipeline implemented in Python using scikit-learn.
- Data ingestion, preprocessing, model training, and evaluation are fully scripted.
- Model artifacts are generated by the pipeline and stored in the appropriate directories. These artifacts are not committed to version control to ensure reproducibility and separation of code and data.

## Roadmap

- **Milestone 2:** Model serving API with FastAPI
- **Milestone 3:** Experiment tracking and model registry integration (MLflow)
- **Milestone 4:** Containerization and deployment workflows (Docker)
- **Milestone 5:** Monitoring, logging, and alerting for production models

## Stack

- Python
- scikit-learn
- FastAPI
- MLflow (planned)
- Docker (planned)

## Getting Started

1. Install dependencies:
	```
	pip install -r requirements.txt
	```
2. Run the training pipeline:
	```
	python training/train.py
	```

## Notes

- Model artifacts and processed data are generated by the pipeline and are not included in the repository.
- The platform is structured for extensibility and can be adapted to various ML use cases and deployment targets.
